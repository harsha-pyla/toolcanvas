How it works

  1. Drop a video or browse — loaded as a local object URL in the preview player.
  2. Set start and end trim points via handles, text inputs, or Set Current buttons.
  3. Preview the selected range, then click Trim & Export Video.
  4. Silent Web Audio rendering captures the video track to WebM for download.

What you get

  • Precise millisecond trim with dual-handle timeline and keyboard access
  • Play Selected Range preview that auto-pauses at the end marker
  • Trimmed duration and type summary in mono data cells
  • WebM output optimized for web sharing — private and offline
