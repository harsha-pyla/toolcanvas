How it works

  1. Drop a video or browse — decoded locally in a hidden video element.
  2. Scrub the timeline or step ±0.1s to find the exact frame.
  3. Select export format and quality, then Capture Current Frame.
  4. Copy frame to clipboard or download snapshots; clear to start again.

What you get

  • Native-resolution frame capture (e.g., 4K) — not monitor-clipped
  • Millisecond timeline seek with frame-step controls
  • Format control: PNG lossless, JPEG/WebP with quality slider
  • Clipboard API copy and batch download — overlay-free output
