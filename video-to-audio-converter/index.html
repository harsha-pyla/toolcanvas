How it works

  1. Drop a video file or browse — audio stream is decoded locally.
  2. Choose channel mode (stereo/mono) and sample rate (44.1/48 kHz).
  3. Click Convert & Download Audio — Web Audio API decodes to PCM.
  4. A WAV file is compiled and downloaded; use Convert another for the next file.

What you get

  • Lossless WAV output with raw PCM data — ideal for editing
  • Stereo (2ch) or mono (1ch) downmix with selectable sample rate
  • 16-bit depth for high fidelity and low noise
  • Private local decoding — no server upload, no limits beyond RAM
